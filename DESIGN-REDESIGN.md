# NGOEffects UI Redesign

This version keeps the existing data model, navigation, location filtering, NGO profiles, impact tracker, and external links intact while updating the visual layer.

## UI changes
- Removed **Search by NGO name** from Explore NGOs.
- Removed **Sector** filtering from Explore NGOs.
- Explore NGOs now filters only by **State → District**.
- Redesigned navigation, hero sections, directory controls, NGO cards, profile view, tracker panels, footer and responsive states.
- Added varied Wikimedia Commons community/education/health imagery to NGO cards.
- Added subtle hover/active states and improved mobile layouts.
- Kept the existing vanilla HTML/CSS/JS architecture so the project remains directly hostable on GitHub + Vercel/static hosting.

## Image note
Card imagery uses Wikimedia Commons Special:Redirect URLs. Wikimedia Commons files can have different licenses and attribution requirements; verify the individual file page before redistribution or commercial use.
